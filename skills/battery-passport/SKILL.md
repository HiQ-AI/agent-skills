# 电池护照与电池碳足迹数据

电池的碳足迹几乎全在材料端。正极用磷酸铁锂还是三元、镍钴来自哪里、电解液和隔膜怎么算、集流体铜箔铝箔多厚 —— 这些逐项加起来决定结果,而每一项都得落到真实的清单数据集上,并且在申报时说得清来源。

本技能负责这批取数与溯源。

## 关于

本技能接入 **HiQ Cortex** —— [海科数据](https://www.hiqlcd.com/)的 LCA 数据智能服务。海科数据是国内 LCA 基础数据与碳足迹服务提供商,自建中国本土生命周期清单数据库,并聚合 18 个国际主流数据源与 24000+ 已发布 EPD。

电池产业链在中国高度集中,材料与电芯的实际生产多在国内 —— **用欧洲数据代表国内产线会系统性失真**,本土清单(HiQLCD 覆盖中国全工业体系、HiQLCD-AL 铝工业数据库、CALCD 中国汽车生命周期数据库)在这个场景尤其重要。化学品与聚合物类材料另有 CarbonMinds 的工艺级数据。

> **关于锂电池专用数据库**:海科数据与中国电子技术标准化研究院等单位联合打造的**中国锂电池碳足迹数据库**(519 条 LCI,覆盖 180 余种物质,贯穿矿产资源、关键材料、电芯、电池包及回收全链条)已发布,但**暂未开放 API 查询** —— 本技能取不到它的数据。需要这批数据请通过 [hiqlcd.com](https://www.hiqlcd.com/databases) 联系。用本技能取数时用的是上面那几个通用与行业库,如实说明即可,不要暗示数据来自锂电池专库。

**检索与候选排序在服务端完成。** 把材料名或 BOM 行原样交给检索接口,翻译与匹配在服务端执行,返回带 `fit` 匹配质量与 `summary` 说明。

## 数据权限

| 层 | 内容 | 要求 |
|---|---|---|
| 目录层 | 各库版本、系统模型、LCIA 覆盖;数据集名称、参考流、单位、地域 | 有效凭据即可 |
| 免费库数值 | BAFU、ELCD、EF、USLCI、worldsteel 等 | 任一有效凭据 |
| 商业库数值 | ecoinvent、HiQLCD、HiQLCD-AL、CALCD(汽车)、CarbonMinds、Agri-footprint | 需对应数据包权益 |

电池材料的高精度数据多在商业库。受限项如实标注并给 `purchase_url`,**不要用免费库的值悄悄顶上去**。

## 硬规则

1. **每个数值都来自本次会话的工具调用。** 电池材料的因子不能凭记忆 —— 这个领域的数据更新快,记忆里的数基本都过时。
2. **每一项都要交代基准**:数据库 + 版本 + 系统模型 + 地域 + 参考流。申报要追溯。
3. **产地必须落实到电芯与关键材料的实际产地。** 电池是电力密集型产业链,产地换了结果就换了。
4. **回收料成分的处理口径要说明。** 用户报了再生成分比例时,说明当前数据对应的是什么口径,不要自己替他选一种算法。
5. **单位对齐**:材料用量(kg/电芯、g/Wh)与数据集参考单位不一致时先换算,换算依据要写出来。
6. **受限不是错误**,给链接,不静默替代。

**另外两条通用的**:

- **给了数值就给链接。** 返回里带 `link` 的,每条结果都一并给出,别等用户追问。
- **不要把 `dataset_key` / `dataset_uuid` 贴给用户看。** 那是给工具用的不透明句柄,
  对人没有意义 —— 展示的是名称、参考流、地域、库+版本+系统模型、数值、链接。
  另注:`dataset_uuid` **不是** `hiq-editor` 里的「背景数据唯一 ID」,别拿去填 `background`。

## 接入

**没有凭据时,第一句话就给扫码登录 —— 不要让用户去控制台建 API key。**

扫码是「跑一条命令 + 浏览器点一下」,无需注册;建 API key 要登录控制台、找入口、
复制粘贴、设环境变量,门槛高出一个量级。把后者摆在第一步会直接劝退用户。

```bash
python3 scripts/cortex.py login      # ← 缺凭据时默认走这条
```

命令会打印一个授权链接。**把链接原样给用户,让他点「授权访问」**,然后继续原来的任务 ——
凭据落在 `~/.hiq/credentials.json`(权限 600),之后所有命令直接可用,可见数据范围与
该账号一致(**包含他已开通的商业数据库**)。

只在这三种情况下才提 API key:用户自己说要用 key、运行在 CI / 服务端无浏览器环境、
或扫码登录失败。

```bash
export HIQ_API_KEY=sk_xxx            # 服务端 / CI 用;同时存在时优先于扫码凭据
```

宿主支持 MCP 时优先用 MCP —— 若当前会话已有 `lookup_datasets`、`aggregate_datasets` 等工具就直接用;没有则把 `https://x.hiqlcd.com/api/cortex/mcp` 配进宿主的 MCP 配置(header 用 `X-API-Key`,或用扫码登录凭据的 `Authorization: Bearer`),配置方式见 [README](https://github.com/HiQ-AI/agent-skills)。

凭据只从环境变量、宿主配置或 `login` 落盘的那份读取 —— **绝不硬编码进为用户生成的文件,也不在输出里回显**。

## 工具

| 需求 | MCP 工具 | 脚本命令 |
|---|---|---|
| 材料 / BOM 行 → 数据集 key | *(无,走 REST)* | `search "<原话>" [--sources X]` |
| key → GWP + 基准 | `lookup_datasets` | `lookup <key> [<key> ...]` |
| 同类分布 / 自有数值定位 | `aggregate_datasets` | `aggregate --source X --target <你的值>` |
| 非 GWP 的 LCIA 指标 | `aggregate_indicators` | `indicators <keys> --indicator AP --source X` |
| 工序级热点(找减排点) | `process_hotspot` | `hotspot <key>` |
| 同类已发布 EPD 参照 | `epd_search` / `epd_peer_benchmark` | `epd` / `epd-benchmark` |

**批量 lookup**:一份电池 BOM 几十项,一次调用传全部 key。检索每次 20–40 秒,项数多时先按材料去重。

## 怎么读返回

| 字段 | 含义 | 该怎么做 |
|---|---|---|
| `summary` | 服务端对本次检索的说明 | 转述,不要另编一套 |
| `fit: high / medium / low` | 匹配质量 | `low` 单列复核,不要混进合计 |
| `name` / `ref_product` / `location` | 数据集名、参考流、地域 | 逐项记录,申报要写 |
| `restricted: true` | 无该库权益 | 该项标注受限,给 `purchase_url` |
| `comparability_note` | 队列可比性说明 | 合计或对比前必读 |
| `missing_keys` | key 来自旧版本目录 | 重新检索 |

## 输出形态

- **逐项**:材料 / 部件 → 数据集(名称 + 参考流 + 地域)→ 用量 + 单位 → 因子 → 小计 → 来源(库 + 版本 + 系统模型)
- **按部件分组**:正极、负极、电解液、隔膜、集流体、外壳与结构件、电芯组装、Pack
- **单列**:`fit: low`、代理数据、受限未取到、用假设换算系数的项
- **合计**:说明边界(到电芯出厂还是到 Pack)与未纳入项

## 语气与术语

面向 LCA 与电池行业从业者写,用 ISO 14040/14044、GB/T 24040 的标准术语,材料用标准名(磷酸铁锂 / LFP、三元 / NMC)。不写客套话,不堆形容词,不做总结式收尾,不自造中文术语。

**不要替用户判定合规义务。** 电池法的适用范围、申报门槛、护照字段要求、核验方式由用户的合规顾问确认。本技能负责数据与溯源。

## 故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 某材料搜不到 | 描述用了内部牌号或缩写 | 用标准化学名或材料类别重试;仍不行就问用户 |
| `restricted: true` | 无该库数据包权益 | 标注受限,给 `purchase_url` |
| 聚合 `status: "empty"` **且带** `entitlement` | 权益问题 | 不要换谓词重试 |
| 聚合 `status: "empty"` **不带** `entitlement` | 谓词没命中 | 放宽谓词 |
| 合计与公开数据差一个数量级 | 多半是单位(kg vs g/Wh)或边界不一致 | 逐项核对参考单位与边界 |
| `missing_keys` 非空 | key 来自旧版本目录 | 重新检索 |
| `401 {"code":"INT-007"}` | 用了 Bearer 或 key 无效 | 改用 `X-API-Key` |
| CDN `error 1010` | 默认 User-Agent 被拦 | 内置脚本已设;直接调用时自带常规 User-Agent |
